Signature Initiative · Engineered in C

A new language for the way we think about code

GlowLang combines readable, expressive syntax with a performance-oriented runtime built from scratch in C — register-based VM, generational memory management, tiered JIT, AI/ML acceleration and native web/database primitives.

Read the Docs Explore the Technology
hello.glow BLUEPRINT // ACTION 
blueprint Hello:
    action init(name):
        self.name = name
    end

    action greet():
        show "Hello, " + self.name
    end
end

let h = Hello("world")
h.greet()

Natural syntax

Keywords that read like intent

The language favours keywords that read close to intent: every and whenever express repeating and reactive behaviour, and when introduces a conditional.

events.glow EVERY // WHEN 
blueprint Counter:
    action init(start):
        self.value = start
    end
end

every 1 second:
    show "tick"
end

when self.value > 10:
    show "limit reached"
end
server.glow BLUEPRINT // HTTP 
blueprint Server:
    action init(port):
        self.port = port
    end

    action start():
        let server = http.listen(self.port)
        show "running on port " + self.port
    end
end

let node = Server(":8080")
node.start()

A runtime built for control
